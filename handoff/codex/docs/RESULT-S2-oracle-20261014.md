## 4. 판정(사전 규칙) — **연결부가 병목이다**

1. 정답을 통째로 담은 잠재로도 (가) 자기/남 구별이 없고(기준 A 불충족), (나) 잠재 없는 순정 모델보다 10 %p 낮다(기준 B 불충족, 반대 방향).
2. 따라서 **투영기 → 64칸 prefix → 고정 LM 경로는 어떤 잠재의 내용도 정답률로 바꾸지 못한다.** 1~4차와 R1·S1에서 DEQ 잠재가 읽히지 않은 것은 DEQ 잠재의 내용 문제 이전에 연결부의 문제다. (DEQ 잠재에 내용이 있는지는 이 연결부로는 알 수 없다.)
3. 잠재 prefix를 붙이는 것 자체가 LM의 풀이를 방해한다(S1·S2에서 일관). 64칸의 학습된 벡터가 문제 글 앞에서 LM의 주의를 흐트러뜨리는 것으로 보인다.
4. 사전 규칙의 다음 단계: **새 연결부 시제품**(10/17~). 후보: LM이 잠재를 cross-attention으로 읽는 어댑터(소수 층), 또는 잠재를 prefix가 아니라 "필요할 때만 꺼내 쓰는" 게이트 잔차. 설계안을 먼저 공유한다.
