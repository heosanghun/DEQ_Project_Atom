## 3. 보조 관찰 (해석, 판정 아님)

1. LoRA는 형식은 완벽히 가르쳤다(`\boxed` 35 → 81~86 %)지만 **정답률은 절반으로 떨어뜨렸다**(15.67 → 7.3~9.3 %). 형식 지킨 답 안 정답률도 36 → 9~11 %. 학습 993문항의 해설 문체에 과적합해 순정 Gemma의 풀이 능력을 깎은 것으로 보인다. S2(고정 LM)에서도 잠재 주입이 해로웠던 결과와 같은 방향.
2. NLL 진단(`INTERIM_NLL_20261019.md`): 시드 2049·2050에서 틀린 잠재는 NLL을 올리지만(z 15.9/9.1), **평균 잠재가 맞는 잠재보다 NLL이 낮다**. 즉 LM이 prefix를 "조금 읽기 시작"했으나 맞는 내용이 상수보다 득이 되지 않는다. 생성 정확도에서도 matched−shuffled +1.1 %p(유의하지 않음)로 일치.
3. 결론(탐색): prefix 자리에 놓는 방식은 LM을 학습시켜도 오라클 내용조차 전달하지 못한다. 연결부 자체를 바꾸는 X3-min(중간 층 cross-attention)이 다음 시험이며, 그 Stage O(오라클)가 "attention으로 잠재 내용을 꺼낼 수 있는가"의 첫 직접 시험이다.
4. 교훈(X3·X4 레시피): LM 쪽을 학습시키면 풀이 능력 손상이 크므로, X3-min처럼 순정 LM 가중치는 고정하고 브리지만 학습하는 쪽이 맞다.
