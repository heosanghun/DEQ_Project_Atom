# X8 — "읽히는 잠재" DEQ 목표 설계안 (CC, 2026-10-21 10:0x, 결과 전 작성; CTO 공유 뒤에만 실행)

## 0. 왜 이 설계인가 (X 계열 결론)
| 사실 | 근거 |
|---|---|
| 잠재를 읽는 통로는 존재하고 재현된다 | X5·X6: 오라클 잠재(정답 해설 은닉 상태) matched − shuffled +3.56 %p, 3시드 합산 CI [+1.61, +5.50] |
| 그 통로로 읽어도 현재 DEQ 잠재(z*′)와 초기 잠재(z_src)에는 문항별 내용이 없다 | X7: A matched − shuffled −1.33 %p(3시드 모두 음수), A − E −1.06 %p 방향 불일치 |
| 정답 해설을 넣어도 순정 대비 이득은 0 | X5·X6: matched − C +0.06 %p |
| 브리지를 정답 해설로 가르치면 해악(−5~−8 %p), 자기 생성문으로 가르치면 해악 소멸 | S2·X1·X3 vs X5·X6·X7 |

결론: G2(A > E, A > C)는 **잠재가 무엇을 담는가**의 문제다. 지금의 DEQ 목표(고정점 수렴·판별)는 "LM이 읽어서 답에 쓸 수 있는 내용"을 만들라는 요구가 없다. 따라서 DEQ 목표에 **읽힘(readability) 항**을 추가해야 한다. 이것은 "연결부 수리"가 아니라 **DEQ 목표 변경**이며 CTO(CTS-435 "설계 먼저 공유")와 교수 미팅(10/28) 안건이다.

## 1. 핵심 아이디어
고정된 순정 LM + 검증된 브리지(X5 레시피)를 **판독기(decoder-as-critic)**로 두고, DEQ 쪽(전이 함수 Φ_θ의 학습 가능 부분 + 투영)을 "판독기가 z*에서 정답을 더 잘 쓰도록" 학습한다.
- 손실: L = L_read + λ_fp·L_fixedpoint
  - L_read: X5와 같은 가중 CE(자기 생성문 표적 + `\boxed{정답}` 구간 가중 5), 기울기를 브리지 **와 DEQ 파라미터 모두**로 흘림(z*는 고정점의 암묵 미분 또는 마지막 K걸음 펼침).
  - L_fixedpoint: 기존 G1 항(수축·잔차)을 유지해 수렴이 깨지지 않게 한다. G1 지표(상대 잔차, k*, 판별)를 매 평가마다 기록.
- 입력은 **문항 글만**(z_src = 문제 인코딩). 해설은 학습 표적에만 쓴다(S2·X 계열과 같은 경계). 따라서 z*가 담을 수 있는 "내용"은 DEQ가 문제로부터 **계산**한 것뿐이다 — 이것이 G2가 묻는 바로 그 질문이다.

## 2. 단계와 사전 규칙
### X8-0 대조(필수 선행, 1일): "문제만 보는 잠재"가 통로로 내용을 전달할 수 있는가
- DEQ 없이, 문제 글 → 작은 인코더(예: 순정 LM의 문제 은닉 상태 64칸 평균/선형 투영, 학습 가능) → 브리지 → 판독 손실로 학습. 시드 3.
- 규칙: matched − shuffled CI 하한 > 0이면 "문제 유래 잠재도 읽힌다"(X8-A로). 아니면 "LM이 이미 아는 문제 글 외의 정보가 없는 잠재는 읽혀도 쓸모가 없다" → DEQ가 **추론 계산**을 추가로 해야만 의미가 있음을 명시하고 X8-A를 그 관점에서 설계·평가.
### X8-A 본 실험(3~4일): DEQ + 판독 손실 공동 학습
- 조건: A = X8 DEQ z*(K걸음), E = 같은 학습을 받은 z_src(K=0, 전이 없음), C-fmt. 시드 3. matched + shuffled.
- 규칙(CTO 기준 그대로): (1) A − E 3시드 같은 방향 ∧ 합산 CI 하한 > 0, (2) A matched − shuffled CI 하한 > 0, (3) G1 지표 유지(상대 잔차·k* 기존 기준 이내). 셋 다 충족 → 5차 사전등록(새 데이터 출처 승인 필요). (2)만 → "읽히는 잠재는 만들었으나 고정점 반복의 이득 없음". 아니면 종결 보고.
- 금지·불변: 학습 993·개발 600만, 새 test 0, 고정 채점기, G2 판정 문서 불변, "통과" 단어는 5차 사전등록·감사·새 문항 판정 뒤에만.

## 3. 비용·일정(예상, 측정 아님)
- X8-0: 학습 3런 × ~30분 + 생성 3런 × ~6시간(GPU 5·6·7 병렬) ≈ 7시간.
- X8-A: DEQ 공동 학습은 걸음당 LM 전방·후방이 더해져 X5의 ~3~5배. 1,500단계 기준 1~2시간/런, 생성 6시간/런, 6런(A·E × 3시드) → 2라운드 ≈ 16시간.
- 10/28 전 완료 가능(10/22 착수 시). 단 CTO 공유·동의가 먼저.

## 4. 위험
- 암묵 미분의 불안정 → 마지막 K걸음 펼침으로 대체(기록).
- 판독 손실이 G1을 깨뜨림 → λ_fp로 조절, G1 지표 매 평가 기록, 깨지면 중단.
- 학습 표적 암기(X6-S 사례) → 답 가중 5·1,500단계 유지, 개발 600으로만 판정.
