## X3 — cross-attention 잠재 읽기 통로 (prefix를 버림)

- 질문: 잠재를 입력 앞에 붙이지 않고, LM 중간 층에서 hidden state가 잠재(64 × 2560)를 **cross-attention으로 조회**하게 하면 내용을 읽는가.
- 설계: 선택한 층(예: 42층 중 4개, 균등 간격)의 출력에 저차원 cross-attention(d_attn 256, 멀티헤드 4)을 덧셈으로 삽입. 출력 투영은 0 초기화(처음엔 순정 LM과 동일). 학습 파라미터 약 10M. 잠재 쪽은 V2 정규화 + 선형 투영. 순정 LM 가중치는 고정. 프롬프트에는 자리표시 64칸을 두지 않는다(형식 지시만).
- 조건: 오라클 잠재로 먼저(X3-O), 통로가 열리면 DEQ z*′ 대 z_src(X3-A/E).
- 판단: X1과 같은 규칙. 통로가 열리면 X4.
