## 1. 작업 그래프 구조

```text
[SERVER_OK] ──▶ [S7_ZSTAR 1,080 계산] ──▶ [S7_DEQ 개입실험: 마스크동결 74문항]
                                               │
                                               ├─ PASS: r<1e-3 ≥80%, r<5e-3 ≥95%, 대조 cos ≥0.999
                                               │   ▼
                                               │ [S7_D 디코더 학습 λ=1, λ=0 (1,080문항)]
                                               │   ▼
                                               │ [S7_D 디코더 평가 (600문항)] ──▶ 게이트 1·2 판정
                                               │                                   │ PASS → S8 (음함수 미분)
                                               │                                   │ FAIL → 진단 노드 (원인 분석)
                                               │
                                               └─ FAIL: r<5e-3 <50%

```

## 2. 노드 상세 및 전이 규칙 (정량 기준)

### 노드 N0: SERVER_CHECK / SERVER_RECOVER
- **진입 조건**: 매 사이클 시작 시점.
- **수행 항목**: `free -g`, `tmux ls`, GPU 파이프라인 로그 마지막 시각 점검.
- **전이 규칙**:
  - 정상 $\to$ 활성 노드 지속.
  - SSH 배너 타임아웃 / OOM 발생 $\to$ `SERVER_RECOVER` 노드 진입 (원장 #381 §0 체크리스트 즉시 수행 후 복귀).

### 노드 N1: S7_ZSTAR_1080 (GPU 0)
- **작업 내용**: Step 1 400문항 + Step 2 680문항 = 1,080문항 $z^*$ 생성.
- **감시 조건**: `s7_watch_and_pause.sh`가 1,080문항 완료 시 파이프라인 자동 일시 정지.
- **전이 규칙**:
  - `zstar_s7_a0.25_train680.pt` 완료 확인 $\to$ 노드 N2 전이.

### 노드 N2: S7_DEQ_EXP (마스크 동결 개입 실험, 74문항)
- **선행 조건**: 동결 검증 301~1000 전 구간 $\max|\Delta| = 0.0$ 원문 로그 첨부 및 사전등록 v1.1 서버 SHA 일치 확인.
- **실행 환경**: GPU 0 (1,080 정지 직후 약 90분 실행).
- **성공 전이 (PASS $\to$ N3)**:
  - 미수렴 54문항 $r < 1\times 10^{-3}$ 비율 $\ge 80\%$
  - 미수렴 54문항 $r < 5\times 10^{-3}$ 비율 $\ge 95\%$
  - 대조군 20문항 $\cos(z_{\text{new}}, z_{\text{old}}) \ge 0.999$ ($z_{\text{old}}$: S6 $\alpha=0.25$)
- **실패 전이 (FAIL $\to$ N2-ALT)**:
  - $r < 5\times 10^{-3}$ 비율 $< 50\% \to$ PREREG_S7_DEQ_v2 (부드러운 라우팅) 수립.

### 노드 N3: S7_D_TRAIN_EVAL (디코더 학습 및 평가)
- **작업 내용**: 1,080문항 학습 ($\lambda=1, \lambda=0$), 600문항 홀드아웃 평가.
- **성공 전이 (PASS $\to$ S8)**:
  - 고정점 주입($\lambda=1$)이 텍스트 단독($\lambda=0$) 대비 통계적으로 유의미한 NLL 개선 및 생성 정확도 향상 입증 $\to$ S8(음함수 미분 공동학습) 진입.
- **실패 전이 (FAIL $\to$ DIAG)**:
  - 기여도 부재 $\to$ 진단 노드(문항별 기여도 분해 분석)로 격하.
