## F1 — 앵커 대조 기준 텐서는 무효 (원인 확인)
- 대조에 쓴 `results_s5/zstar_s5_anchor20.pt`의 기준 파일은 `auto24h/zinj3_g0.25_a0.5_20q_nfe1000_…pt`이다. 즉 **α = 0.5**이고, 일부 문항(Q#40·Q#44 등)은 **σ = 1.0**이다(S5 기록 94·107~108행). S7 정본은 α 0.25, σ 0.020이다. 따라서 14/20 미달은 설정이 다른 데서 나온 것이며 장치 차이의 증거가 아니다. 수렴한 문항(Q#20 r≈1e-6)만 cos≈1인 것도 같은 고정점에 다른 감쇠로 도달한 경우와 맞다.
- S7 α 0.25의 GPU 0 앵커 텐서는 저장된 적이 없다(P1은 로그만 남김).
- 현재 근거는 두 가지다: GPU 1과 GPU 2가 서로 bitwise로 같다는 것, 그리고 20문항의 r_1000·k*가 P1(GPU 0) 로그와 같다는 것(k*는 1,000걸음 궤적의 정수 지문). 장치 동등성을 **잠정 인정**한다.
- v1.3 §10(f) 문언(정본 z_1000과 비교)을 채우기 위한 조치: P4'가 끝나 GPU 0이 비면, z_src·P6보다 **먼저** GPU 0에서 앵커 20을 같은 실행기·시드 2030으로 계산해 텐서를 저장하고, GPU 1·2 텐서와 CPU로 대조한다. **P5·P5b 결과는 이 대조와 분석기 v3 감사가 끝난 뒤 연다.** 대조가 기준에 미달하면 A가 판정하고 Principal에게 보고한다.
