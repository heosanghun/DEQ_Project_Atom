## 분석기 (`scripts/p5_analyze_v2.py`, SHA `bed923d3…` 로컬 일치)
- 일치: 질의/갤러리 방향 정확 — `cos_mat = compute_cos_matrix(z2, z1)`(207행, z2=시드2 파일, z1=⑦ z_star), `argmax(dim=1) == arange`(210-211행). 펼침 `view(n,-1)`(204행), 평균 풀링 `mean(dim=1)`(205행), 다중 평형 `diag < 0.99`(215-216행), 분위수 보고(225행). ⑦ 쪽은 `z_star`만 사용(63·444행).
- 불일치 1(분모·결측): 193행 `valid_qids = 두 파일 교집합`으로 결측 문항을 조용히 버리고 분모·갤러리를 n_valid로 줄임. (g)는 "520 중 515 이상", "j = 520개 전체". 결측 시 판정이 관대해질 수 있음.
- 불일치 2(동률): `argmax`는 첫 최댓값 인덱스를 돌려주므로 동률이면 i가 더 작은 인덱스일 때 성공으로 셈. (g)에 동률 규칙 없음.
- 위험 3(표현 대체): 시드2 로더 `load_raw_z_dict`는 `z_star`가 없으면 `z_lowest`로 대체(91-94행). (g)의 "z_star(최종점)" 표현을 조용히 벗어날 수 있음.
- 위험 4(정밀도): 행렬 cos가 float32(179-181행). LESSONS 2(노름 float64)와 다르고 0.99 경계·근접 동률에서 뒤집힐 수 있음. 판정값은 float64 권고.
- 위험 5(시드 검증): 출력 키 `q{idx}_a0.25`에 시드 정보가 없고 실행기는 기존 키를 건너뜀(106-109행). 파일을 잘못 지정하면 같은 z끼리 비교해 100 %가 됨. 분석기에서 두 파일 경로가 다르고 대각 cos가 전부 1.0이 아님을 확인하는 단언 권고.
