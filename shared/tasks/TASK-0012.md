- `--nn_mode {none,seedpair,zsrc}` 인자를 추가한다. 기본값은 none.
  - seedpair([A]): `--seed2_file`(2회차 .pt, 같은 키 형식)을 받는다. 각 i에 대해 2회차 z*_i를 1회차 z*_j 520개와 비교해 cos 최대인 j가 i인 비율을 낸다. 다중 평형 비율 = cos(z*_i 1회차, z*_i 2회차) < 0.99인 비율. cos 분위수도 낸다.
