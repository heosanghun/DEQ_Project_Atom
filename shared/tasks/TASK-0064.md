   - `tokenizer.eos_token_id`, `tokenizer.encode("<turn|>", add_special_tokens=False)`, `tokenizer.encode("<end_of_turn>", add_special_tokens=False)` 각 ID와 `tokenizer.convert_ids_to_tokens(...)` 조각 원문
   - 실행기와 같은 코드로 만든 `eos_set` 전체(정렬)와 각 ID의 조각
   - 토크나이저 특수 토큰 목록 중 `turn`이 들어간 것과 ID
2. `results_s7/p6_gen_{A,B1,C,E1,F,D1,D21,E21}.jsonl` 각각(있는 것만)에 대해:

   - "조각 정지 의심" 행 중 3개의 생성문 끝 200자(원시 문자열로)
