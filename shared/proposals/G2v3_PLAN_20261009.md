# G2 3차 시도 설계 메모 (GRAPH N8: DEQ를 풀이 손실로 학습) — CC, 2026-10-09 00:2x, 초안

## 1. 왜 3차인가 (근거)
- 1차(P6R): 정본 z*는 문제 정보를 잃어 디코더에 잡음(게이트 4 −4.83 %p).
- 2차(M2′ 개발): 주입 교체로 z*′가 z_src 정보를 보존 → z 디코더가 글만보다 크게 개선(A′ 7.50 % 대 C 0.33 %). 그러나 A′ ≈ E′(7.50 대 7.83, NLL 0.892 대 0.846). **고정점은 z_src를 보존할 뿐, 반복이 풀이에 쓸모 있는 계산을 더하지 않는다.**
- 반복 사상 Φ(라우팅·LoRA·γ)는 Stage 1에서 "고정점 잔차 + LM 보존" 목표로만 학습됐고, 수학 풀이 손실로는 학습된 적이 없다(GRAPH N8 "디코더 손실을 음함수 미분으로 전이 함수까지 학습"이 원래 계획).

## 2. 방법 후보 M3 (주)
- 고정점 반복은 M2′(주입 = z_src) 그대로.
- 학습: 디코더(투영기)와 DEQ 사상의 학습 가능 부분(LoRA·routing_proj·γ)을 **함께** 정답 해설 NLL(λ = 0)로 학습한다. 고정점까지는 기울기 없이 풀고(warm start, tol), z*에서 한 걸음 "환영 기울기(phantom gradient)"로 사상 매개변수에 기울기를 보낸다(Stage 1 `fixed_point_surrogate_loss`의 방식 재사용).
- 안정성: 학습 중 잔차 r(z*) 감시, Stage 1의 IFT 잔차 손실을 보조로 유지(수렴 유지).

## 3. 공정한 비교(게이트 4)
- GOAL.md 정의대로 E = "자기 z_src, 별도 학습 디코더". 그러나 M3의 A는 학습 가능한 매개변수(DEQ 부분)를 더 가진다. 용량 차이 혼입을 막으려고 **E 쪽에도 같은 학습 가능 사상을 한 번만 적용한 대조**(E‴: z_src → Φ_θ 1회 → 디코더, 같은 학습 예산)를 둔다. 주 게이트 4는 사전등록에서 어느 대조를 쓸지 B 감사와 함께 정한다(권장: E‴, 더 엄격).

## 4. 절차 (2차와 같은 틀)
1. 소규모 파일럿(학습 문항 일부): 학습 안정성·수렴·속도 측정, 개발 NLL로 A−E 방향 확인(개발용).
2. 사전등록 PREREG_S7_G2v3 작성 → B 감사 → 잠금. 3차 시도 번호 명시, 1·2차 결과 공개.
3. 학습 1,000문항으로 학습, 개발 600으로 선택 규칙 확인.
4. 규칙 충족 시 확증: **2차에서 열지 않은 새 1,000문항**(`configs/g2v2_fresh1000.json` 35683874…)을 그대로 쓸 수 있다(2차 사전등록 §2 마지막 줄). 반복 시도 보정 참고값(× 3)을 보고.

## 5. 예상 비용
- 학습 단계당 배치 8문항 고정점 풀기(배치 반복, tol 사용) + 한 걸음 역전파. 파일럿으로 실측. 거친 추정: 단계당 10~30초 → 3,000단계 8~25시간(GPU 5·6·7 분할).
- 설계·코드·감사 약 0.5~1일, 학습 약 1일, 평가 약 0.5일 → **3차 결과 약 2~3일 뒤**.

## 6. 위험
- 매개변수를 학습하면 고정점 수렴이 깨질 수 있다(G1 성질 손실). 잔차 감시·보조 손실로 대응, 보고.
- 학습이 반복을 "z_src 복사"로 수렴시켜 A ≈ E로 끝날 수 있다. 이 경우 4차 방향(예: 디코더가 글 없이 z만 보는 조건 — GOAL 개정 필요)을 Principal과 상의.
