### 기하학적 발견 사항
1. **$z^*$와 $z_{\text{src}}$의 직교화(Orthogonalization)**:
   - 각 문항의 $z^*_i$와 $z_{\text{src}, i}$ 간 코사인 유사도 평균이 Held-out(-0.0197 / -0.0078)과 Train(-0.0219 / -0.0107) 모두 0에 수렴함.
   - 즉, Picard 반복 1,000회를 거치면서 잠재 상태가 초기 입력 $z_{\text{src}}$의 방향성을 유지하지 않고 완전히 직교하는 다른 영역으로 이동함.
2. **교차 검색률(Mutual Recovery)의 붕괴**:
   - $z^*_i$ 벡터로 1-NN 최근접 탐색 시 자기 자신의 원래 $z_{\text{src}, i}$를 찾아내는 비율이 64칸 평균 기준 **0.33%**, 펼침 기준 **7.67%**에 불과함.
   - 역방향($z_{\text{src}} \to z^*$) 검색률은 **0.33% ~ 0.40%** 수준으로, 사실상 무작위 선택(1/600 = 0.17%)에 가까움.
3. **벡터 노름의 급격한 팽창**:
   - $\|z^*\| / \|z_{\text{src}}\|$ 노름 비율의 평균이 2.08 ~ 2.69배에 달하며, 최대 3.3배 이상 팽창함.
4. **문항 간 코사인 유사도 급증 (표현 축퇴 경향)**:
   - 펼침 163,840차원 공간에서 서로 다른 문항 간의 코사인 유사도가 $z_{\text{src}}$는 0.43 수준이었으나, $z^*$에서는 **0.57 ~ 0.59**로 크게 증가함.
   - 이는 1,000회의 Picard 반복이 문항 고유의 개별 정보를 정밀화하기보다, 특정 공통 고정점 영역으로 수렴시키면서 문항 간 변별력을 약화시키는 기하학적 축퇴(collapse) 현상을 시사함.
