# CTS-433 — CTO(안수진 박사) 답신 (2026-10-13 13:44~13:46, 사용자가 전달한 캡처를 CC가 옮겨 적음)

1. 4차 M7 양성 결과는 시드 2047에서는 유효하지만 여러 시드에서 재현되는 M7의 일반적 효과는 아님. NLL이 no-injection보다 크게 좋아졌지만 matched와 shuffled 차이가 매우 작아, decoder는 문항별 정보를 읽기보다 latent가 들어오는 것 자체를 공통 soft prompt처럼 이용하는 것으로 보임. 원래 GOAL의 G2는 아직 미통과로 정리.
2. 5차와 새 test 데이터 개봉 중단은 잘한 결정. 새로운 학습을 바로 시작하기보다 기존 로그와 체크포인트로 시드 2047이 달랐던 이유부터 확인: 시드별 projector 크기, gradient, matched–shuffled 차이, \boxed{} 비율, 생성 길이 비교.
3. A 안정화, 새 latent 학습 목표, IFT는 동시에 진행하지 말고 진단 결과와 설계안을 먼저 공유. IFT는 문항별 정보 기여 문제를 해결한 뒤.
4. 결국 DEQ 반복이 문항별로 유용한 정보를 추가한다는 핵심 가설이 확인되지 않음. 구조를 더 바꾸기 전에 시드 2047의 양성 결과가 왜 나왔는지부터 확실히 정리.
